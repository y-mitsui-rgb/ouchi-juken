おうち受験ラボ — アプリとして 入れる ための セット
====================================================

この フォルダを そのまま インターネットに おくと、
スマホの ホーム画面に 「アプリ」として 入れられます。


1. 中身
----------------------------------------------------
  index.html              アプリ本体（1まい だけで 動きます）
  manifest.webmanifest    アプリの なまえ・アイコン・色の 設定
  sw.js                   オフラインで 動かす ための しくみ
  icons/                  アイコン画像（192 / 512 / マスカブル / iOS用180）


2. おきかた（アップロード）
----------------------------------------------------
  HTTPS で 見られる ところに この フォルダを おきます。
  無料で つかえる おきばの れい:

    Ａ）GitHub Pages
        1. GitHub で あたらしい リポジトリを つくる（Public）
        2. この フォルダの 中身を すべて アップロードする
        3. Settings → Pages → Branch を main / (root) に して 保存
        4. しばらくすると https://<ユーザー名>.github.io/<リポジトリ名>/ で 見られます

    Ｂ）Cloudflare Pages / Netlify / Vercel
        「フォルダを ドラッグ＆ドロップ」で おけます。
        ビルドの 設定は 不要です（そのまま 静的ファイルとして おくだけ）。

  ※ index.html と 同じ フォルダに manifest.webmanifest と sw.js、
     icons/ を おいて ください。フォルダの かたちを かえないで ください。


3. スマホに 入れる
----------------------------------------------------
  ・iPhone（Safari）
      Safari で ひらく → 下の 「共有」 → 「ホーム画面に追加」 → 「追加」
  ・Android（Chrome）
      Chrome で ひらく → 右上 「︙」 → 「アプリを インストール」
      （または 「ホーム画面に追加」）

  ホーム画面の アイコンから ひらくと、アドレスバーの ない がめんで
  ひらきます。ネットが なくても 動きます。


4. きろくに ついて
----------------------------------------------------
  お子さまの きろくは、端末の ブラウザの なか（localStorage）に
  だけ 保存されます。サーバーには おくりません。
  アプリは ひらいた ときに、ブラウザに 「この データは けさないで」
  と おねがい します（Storage API）。ホーム画面に 入れて つかうと、
  さらに 消えにくく なります。

  ときどき 「おうちの方」→「データの ひきつぎ」→「ファイルに 書き出す」
  で バックアップして おくと 安心です。
  書き出した ファイルは、あたらしい 端末の 「ファイルから 読みこむ」で
  そのまま つかえます。


5. バージョンを あげた とき
----------------------------------------------------
  index.html を 入れかえた だけでは、キャッシュが のこって
  古い 画面が 出る ことが あります。
  sw.js の 1行目  CACHE = 'ouchi-juken-v1'  の v1 を v2 に あげて ください。
  それで 古い キャッシュが 消えて、あたらしい 画面に なります。

おうち受験ラボ — GitHub Pages に おく 手順（ブラウザだけで できます）
=====================================================================
所要 5分。むずかしい 操作は ありません。git の コマンドも つかいません。


■ 0. まえに かくにん
  この フォルダの 中身が そのまま サイトに なります。
  フォルダの かたち（ファイルの ならび）は かえないで ください。

    index.html              アプリ本体
    manifest.webmanifest    アプリの 設定
    sw.js                   オフラインの しくみ
    icons/                  アイコン 4まい
    .nojekyll               GitHub の 余計な 加工を とめる ファイル
    README.txt              せつめい（おいても おかなくても 大丈夫）

  ※ .nojekyll は 「ドットで はじまる ファイル」です。
     パソコンの ファイル一覧で 見えない ことが ありますが、消さないで ください。


■ 1. GitHub の アカウントを つくる
  https://github.com/signup
  メール・パスワード・ユーザー名を きめます（無料）


■ 2. リポジトリを つくる
  1. https://github.com/new を ひらく
  2. Repository name に   ouchi-juken   と いれる
  3. Public を えらぶ（無料で Pages を つかう ため）
  4. Create repository を おす


■ 3. ファイルを アップロードする
  1. つくった リポジトリの 画面で  「uploading an existing file」 の
     リンクを おす（なければ Add file → Upload files）
  2. この フォルダの 中身を 【すべて えらんで】 ドラッグ＆ドロップ
     （index.html・manifest.webmanifest・sw.js・icons・.nojekyll・README.txt）
     ※ フォルダごと ではなく、フォルダの 【中のもの】 を 入れます。
        しまうと アドレスが 1つ ふえて、アプリが ひらかなく なります。
  3. したの ほうの  Commit changes を おす


■ 4. Pages を オンにする
  1. リポジトリの Settings（歯車）を おす
  2. ひだりメニューの Pages を おす
  3. Source は  Deploy from a branch
     Branch は  main 、フォルダは  / (root) にして Save
  4. 1〜2分 まつと、うえに アドレスが 出ます:
       https://（あなたのユーザー名）.github.io/ouchi-juken/


■ 5. スマホに 入れる
  うえの アドレスを スマホで ひらきます。

  ・iPhone（Safari）
      Safari で ひらく → 下の 「共有」 → 「ホーム画面に追加」 → 「追加」
  ・Android（Chrome）
      Chrome で ひらく → 右上 「︙」 → 「アプリを インストール」

  ※ 「ホーム画面に追加」は Safari（iPhone）で おこなって ください。
     Chrome など ほかの アプリから では うまく いかない ことが あります。
  ※ アドレスは https で はじまって いる 必要が あります。
     http や file:// では インストール できません。


■ 6. あとから アプリを なおした とき
  1. リポジトリで index.html を ひらく → 鉛筆マーク → 中身を 入れかえる
     （または Add file → Upload files で 上書き）
  2. そして 【かならず】 sw.js の 1行目を さがして

        const CACHE = 'ouchi-juken-v1';

     の v1 を v2 に あげて ください。
     これを しないと、スマホに 古い 画面が のこって しまいます。


■ こまった とき
  ・アプリが ひらかない → index.html が リポジトリの 【いちばん 上】 に
    あるか かくにん（フォルダの 中に 入って いないか）
  ・インストールの 案内が 出ない → https か かくにん。1〜2分 まってから
    再読みこみ
  ・アイコンが 白い → 追加しなおし（iPhone は アイコンを おぼえるため、
    いちど けして もういちど 追加）
  ・きろくが 消えた → 「おうちの方」→「データの ひきつぎ」→
    「ファイルから 読みこむ」で バックアップから もどせます
